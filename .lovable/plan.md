# Correct dates on teacher performance letters

## What will change
- Add an examination date to every class, Series, and academic-year record.
- Fill existing Series dates from the earliest recorded marks for that class and Series, so old letters no longer use today's date.
- Let Admin and the relevant Head of School set or correct the date from Series Control; newly opened Series will require a date.
- Return the applicable examination date with each teacher letter and use it in both the on-screen preview and downloaded PDF.

## Technical details
- Extend the existing Series Control records instead of creating a separate schedule.
- For a teacher covering multiple classes in one Series, use the latest applicable examination date among those classes.
- Keep current role restrictions and performance calculations unchanged.
